# WattWise-Smart-Energy-Saving-System
A responsive landing page for **WattWise**, a Pakistan-based smart energy platform that helps homes and businesses reduce electricity usage and monthly bills.

## Overview

This project is a static frontend website built with:

- HTML5
- CSS3
- Vanilla JavaScript

It includes a modern hero section, feature highlights, pricing, testimonials, and a contact form.

## Features

- Sticky navigation with mobile menu toggle
- Smooth-scrolling section links
- Animated section reveal on scroll (Intersection Observer)
- Responsive design for desktop and mobile
- Video hero background with image fallback
- Contact form submit interaction (UI feedback)
